  **这两个"用道具"的任务是两种怪，道具名也不一样**：招魂帖是**招魂幡**的、逐妖蛊虫是**逐妖蛊虫**的。曾经把招魂帖的文案当成逐妖蛊虫的例子写进注释和测试（用户指出来过）——代码里四条正则只看"地图名+坐标"、不看怪名道具名，所以逻辑没错，但注释/测试/文档写错会把后来的人带沟里。`sec_bell` 里现在有一条 `六种怪的真实文案逐个认` 盯着这张表。**六条现在全是逐字原文**（2026-10-16 晚上补齐：招魂幡/逐妖蛊虫/梦魇魔 换成用户当晚给的 1:1 截图原文 —— 老版本的首句和尾巴是猜的；迷幻妖/怯弱妖=截图、巧智魔=真机 bell.log）。

  **每一拍读到的字还要过一层"话术门槛"**（`BELL_WORDS` / `has_bell_words`，用户定的 2026-10-16 晚）：面板那一拍读到的**整段文字**里必须含 `使用 / 踪迹在 / 招魂 / 蛊虫 / 妖魔 / 梦魇魔 / 迷幻妖 / 巧智魔 / 怯弱妖` 里任一个，才认那段里的"图名+坐标"；一个都没有就当**读花**（不报、也不进"待确认"，也不进 `dlg_text`；心跳里 `话术门槛挡下 N 次` 能看到它挡了几次）。挡的是**唯一一条"两遍一致"防不住的误报路径**：面板收紧失败（`box = 整块`）时会把下方的聊天/世界频道一起读进来 —— 聊天里一句「去长寿村(50,60)集合,别乱跑」正好长成"图名+坐标"，而它是**静态行**，两遍必然读成一样。门槛用"或"、都挑短的：OCR 丢一两个字还剩别的词能命中（整句模板一丢字整条就废）。**任务栏那一支不吃这道门槛**：它已经有"见过两次"这道复核；更要紧的是悬停那行（`在建邺城(15,122)处`）单独读出来时**一个核心词都没有**，吃了会把 hover 档废掉。回归用例：`sec_bell` 的「话术门槛:面板里读到聊天那种「图名+坐标」被挡下」「话术门槛:六种怪的对话框原文都过得了（别把自己的任务挡了）」。

  对应到 `tools/bell.py`（**对话框优先、任务栏补充**；**已经不做"两处对不上就立刻再扫"**，2026-10-16 按用户要求整套删了）：
  - `scan_bell_parts(blocks, scoped=True)` 把一轮文字块拆成 `(dialog, tracker, where)`：dialog =「踪迹在…」或「去X(x,y)使用…」（最权威），tracker =「妖魔在…/在…处」（任务栏或悬停），where 恒为 `None`（「去X找Y」只有图名的**一律不管**）。`_RE_BELL_TRACK` 带 `(?<!踪迹)`，不然对话框那半句的"在"会被当成任务栏说的。
  - **`wide` 宽窄口径已删**（2026-10-21）：它是给"整窗那一拍"防聊天行用的，整窗那条路删了（见下面「任务栏框来自分辨率表」），现在喂进来的都是**小块**（对话框文字带 / 表里的任务栏框），"没锚点"的两条兜底（`_RE_BELL_KNOWN` / `_RE_BELL_ANY`）照旧全开 —— 小块里图名读花（"建邮城"/"宝国"）靠它们接。
  - `BellTool.tick`：**一个杀怪周期 = 一次"对话框给出图+坐标"**（`self._cycle`）。周期内只有任务栏给出**新的图+坐标**才更新（逐妖蛊虫用道具后就是这种）；任务栏只写地图没坐标的**一律不管**（用户明确要求，界面也不显示半成品）。同一条提示不重复记（`_last`）；坐标落在地图范围外的当读花、**不报**（`in_bounds`）。
  - **扫哪**：**全自动**——永远扫整个客户端窗口（`regions()` 恒给一个矩形），对话框/任务栏靠文字认。**手动框选已删除**（用户 2026-10-17：不支持手动框了），也没有 `bell_rect` 配置。（注意"region 是哪块"和"整窗扫"是两回事：后者 2026-10-21 起已不存在。）
  - 地图名必须过 `known_map()`（= 归一后属于那六张；**用户确认铃铛只去这六张**，所以"某某地(12,34)"这种一律不认，别的任务/聊天的地点不会误当成妖魔位置）；`_RE_BELL_KNOWN` 兜底认"没锚点但图名认识"的老写法（现在读的都是**小块**：对话框文字带 / 表里的任务栏框）。
- **地图名要能容忍 OCR 认错字**：`_BELL_CANON` 收常见错法（实测把"建邺城"读成**建邮城**，整条提示就废了；还有 西粱/宝像/敖来/常寿/长寿郊外），`known_map()` 最后还兜一条"**对得上至少两个字且只对得上这一张**"（治"宝象国"被读成"宝国"）。新增地图名时把错法一起补进去 —— 宁可多认几个字，别漏掉整条提示；但也别放太松（"长安"跟"长寿村"只共一个"长"，放进来就会把别的任务当成铃铛）。
- **任务追踪里挂着多个任务,只认「降妖伏魔」标题下的那一段**（`_bell_scope`）：别的任务也有"去某某地(x,y)"的行,不圈范围就会认错。保留三种块：①标题下 200px 内的行 ②对话框说的（「踪迹在…」/「去X(x,y)使用招魂帖」）③「妖魔在…」（这句话只有铃铛任务会说,标题被 OCR 漏了也能兜住）。找不到标题时,任务追踪的行全部作废,只剩对话框。

## 全部细节（原文，2026-10-17 从 AGENTS.md 原样搬来）

**底图现在随仓库分发**（2026-10-21 用户定的，提交 `a2023ae`）：`data/maps/` 下是六张官方地图截图（`<中文名>.png`）+ `bounds.json`（坐标范围）+ `calib.json`（坐标↔像素标定），clone 下来即可用。**想自己重采仍可**（`gui.record_map`，界面入口已撤，见下）；原项目一度因为游戏素材的版权风险把底图全部删掉、只留一键录入，那是本应用之前的状态。

- `tools/bell.py:find_map_rect(rgb, want_ratio=None)`：**两条路互补**，返回 `(x0,y0,x1,y1)` 或 `None`。
  1. `find_color_blob`：逐级试彩色度档 `sat>35/25/45/55`，每档取"边长 160~1500 + 连通块占外接框 ≥0.55"的块，再按"外接框长宽比离 `want_ratio` 最近"打分（偏差 >3% 不要）；每块还按"行/列覆盖比例 ≥0.5 的最长连续段"裁一次当第二候选。五张图靠它命中（0.2~0.5s，全屏约 1.4s）。
  2. `find_map_frame`（兜底）：**地图窗那圈深色外框**。判据是"细深色长条"——某行/列有很长的深色连续段，且这一段**外面至少一侧是亮的**（是线，不是深色面积块）；上下两条横线的跨度要基本重合、左右两条竖线的跨度要落在两条横线之间，四条线框出的矩形边长在区间内、长宽比离 `want_ratio` 差不超过 12%（外框比本体多一圈边，比例会漂），然后在框内**再跑一次 `find_color_blob`** 拿到本体。**建邺城（灰石头城，彩色度全图最低）只有这条路认得出**（1.4~5.6s）。
  - 实测（把官方地图窗截图贴进真游戏截图做的全屏模拟）：**六张全部命中，与地图本体差 ≤1px；三张没开地图的真截图 × 六张图 = 18 个反例全部拒**。`want_ratio` 由 `map_ratio(name)` 从 bounds.json 算（六张图与底图差 ≤1%），既是挑选依据也是校验。
- `tools/bell.py:map_names_in(blocks)`：画面文字里出现过哪几张地图名（去重 + 别名归一）。核对规则：录的那张没出现在画面里、却读到了另一张 → 拒绝；一张都没读到 → 仍然放行但在日志里写明"没读到地图名(没核对)"。地图窗口里那些**邻近**地图的标注（解阳山/丝绸之路…）不在 `BELL_MAP_NAMES` 里，不会被算进来。
- **降妖伏魔小窗只有一扇窗**：没有顶栏（牌匾和「地图采集」按钮 2026-10-20 撤了），从上到下就四块 —— **地名行（地名左、坐标右）+ 地图（红点）+ 底行（角色名 + ☀/☾ + ↻）**；没有卡片、没有金框、没有状态行（2026-10-21 用户选的「深色 HUD」A 方案）。**没有「降妖伏魔」抬头**（2026-10-21 用户定的）。右侧抽屉照建但**没有入口**（见下面那条）。**窗口最外一圈 1px 描边**（色板 `win_edge`；深色底压在深色场景上时只靠系统阴影分不清窗口边界，2026-10-21）。**窗口位置会记住**：退出时 `App.save_bell_pos()` 写 `bell.bell_pos = [x, y]`，下次启动 `set_place(pos=...)` 摆回原处（`ui/widgets:usable_xy` 要求标题栏还在屏内，否则退回居中；用户 2026-10-21 要求——之前每次启动都压回屏幕正中）。**皮肤首启跟随系统**：`core.default_ui_mode()` 在没选过 `bell.ui_mode` 时读注册表 `AppsUseLightTheme`（明亮→B / 深色→A，读不到按深色），选过就以配置为准。
- **界面上不出现「监听/定位」这类文案**（用户定的 2026-10-21）：没有状态行、没有「自动定位」按钮 —— 换客户端收成**一个圆角框**（`bell_client_chip`，2026-10-22 用户定的）：框里只有**角色名**（无三角），**宽度 = 7 个字的宽**（`ui_bell.chip_width`，长名字末尾省略），点一下 = **重新定位一次**，**客户端列表从药丸头上浮出来**、盖在地图上（方案 E，窗口尺寸一步不动；再点一下药丸收起）；按住时字变金色。**右下角**是一颗无文字的 **☀/☾**（`bell_theme_btn`），点一下在**深色 A / 明亮 B** 两套皮肤之间切（2026-10-21 用户要求），选择存 `bell.ui_mode`（`"a"` 深色 / `"b"` 明亮）。定位到哪台客户端就写**那台的角色名**在框里（`client_name(bell_client)`），没定位到就写占位句「暂未找到客户端」（`ui/bell.py:set_client`，不留空——留空用户看不出是没找到）。**不再有 hover 文字提示**（2026-10-22 用户取消）：以前"鼠标停上圆钮把底行字换成『换客户端』"那套会因提示比名字短把按钮挤走、Enter/Leave 打架整行狂闪，已连同 `_hint` / 宽度锁死一起删掉。**点框没找到客户端不弹模态框**：`ui_bell.flash_foot()` 在框里写 1.6 秒红字「没找到客户端」再还原（`FLASH_MS`；2026-10-21 用户定的——模态框要点「确定」才算完，会打断游戏）。**客户端矩形不再显示**（用户 2026-10-20）；「自动监听」「日志 ▾」「框选区域」「清除」都已撤（监听常开、日志只进 `bell.log`）。
- **红色虚线网格烘在底图里**（用户 2026-10-21 定：**不是运行时画线**，直接改进 `data/maps/*.png`）：`傲来国.png` / `朱紫国.png` = **7 列 × 5 行**，`长寿村.png` = **5 列 × 7 行**（竖图），建邺城 / 西梁女国 / 宝象国**不画**。按底图像素等分、颜色 `#ff2d2d`；线宽/划长按"显示到 400px 宽时的观感"反推（傲来国、朱紫国 2px、划 8 空 5；长寿村 1px、划 5 空 3）。**图尺寸没变，所以 `calib.json` / `bounds.json` 都不用动**。要改行列 = 重烘底图，别在 `draw_bell` 里加线（运行时画的那版已撤，2026-10-21）。
